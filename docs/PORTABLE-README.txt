DeadVox - beta 0.1.0-beta.2

This is a beta for testing. Some dubbed lines still await in-game quality
review. Please report playback or installation problems to the project team.

1. Keep the application folder in a writable location and open DeadVox.exe.
2. Wait for the update check, then choose Download voices on the PT-BR card.
3. Close Deadlock, select PT-BR, then use Play Deadlock.
4. To restore the game's voices, close Deadlock and select Original.

The launcher downloads voice packs beside the executable. Keep the application
folder writable and allow sufficient disk space for downloading and installation.
Voice packs and launcher updates use the official release channel fixed by the
developer: github.com/pedrommartini/deadvox-downloads. Launcher updates are
applied only after confirmation in the Updates dialog.
Use Settings to choose a game folder if Steam auto-detection cannot find it.
During operations, the Play button shows progress and window closing is blocked.

The local PT-BR packs include Lady Geist (1,835 lines), Archmother (898), Hidden
King (880) and The Urn (341). Original performances are preserved. Other
characters do not yet have a voice pack in this local build.

Steam, Deadlock, Windows x64 and WebView2 are required.
Settings and backups are saved under user-data beside this executable.
PT-BR loads before Deadlock Mod Manager addons. Starting through DeadVox
restores the selected PT-BR configuration if Steam or the mod manager changes it.
Selecting Original turns off this automatic PT-BR restoration.

Hero portraits: Valve, via Deadlock API.
